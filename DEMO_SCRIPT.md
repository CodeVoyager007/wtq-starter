# 2 minute demo script

Practice this out loud twice. Keep sentences short.

## 0:00 - 0:20 The problem (Home page)

- "Hi, I'm Ayesha. Our challenge was: _[one sentence from the challenge]_."
- "This matters because _[who suffers, in one line]_."

## 0:20 - 0:40 The idea

- "So we built _[Project Name]_. You give it _[data / text]_, and it gives you _[answer]_ in seconds."

## 0:40 - 1:30 Live demo (Workspace page)

1. Load the challenge data (already uploaded before you start, do not waste time on this live).
2. Type ONE strong question or input you tested 3 times before.
3. Press Run. While it thinks, say: "It reads the columns first, then Gemini plans the steps."
4. Point at the result: the answer, then the table or chart, then "Show the code the AI wrote" or the sources.
5. Say: "Every answer comes with proof, so you can check it."

If the model is slow or fails, do not panic. Say "the model is busy" and show the result you saved in a screenshot.

## 1:30 - 1:50 How it works (How it works page)

- "Next.js frontend, FastAPI backend, Gemini for reasoning, pandas for the real calculations."
- "We keep the AI honest by running real code and showing sources."

## 1:50 - 2:00 Close

- "Next we would add _[one thing]_. Thank you, I'm happy to take questions."

## Questions judges may ask

- **What if the AI is wrong?** We show the code or sources, and we check results by running real calculations.
- **What about privacy?** Files stay in memory for the session only, nothing is stored.
- **Why this approach?** Fast to build, easy to check, and works on any table or text.
- **What would you build next?** _[your answer]_

## Before you walk on stage

- [ ] Backend and frontend running, data already loaded
- [ ] Tested question typed in a notepad, ready to paste
- [ ] Screenshot of a good result saved as a backup
- [ ] Wi-Fi checked, phone hotspot ready, laptop charging
